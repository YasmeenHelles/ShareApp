# شير — ShareApp

Arabic right-to-left login screen inspired by the supplied design.

## Web preview
Open [index.html](./index.html) directly in a browser, or enable GitHub Pages (Settings → Pages → Deploy from a branch → main → /root). Once published, the page will be available at the repository's GitHub Pages URL.

## React Native / Expo
Install Node.js LTS, then run:

```bash
npm install
npx expo start
```

Press `w` to launch the Expo web app, `i` for the iOS simulator, or `a` for Android.

## Files
- `index.html` — standalone interactive browser preview
- `App.js` — React Native login screen
- `app.json` — Expo configuration
- `package.json` — scripts and dependencies

## Note
Login, account creation, password recovery, and social sign-in are UI demonstrations. Connect an authentication backend and OAuth providers before production use.
